# Fuin Wallet v0.1 Requirements

Fuin Wallet v0.1 is an MVP alpha for developers using Codex, Claude Code, Cursor, and MCP-based agents.

## Runtime

- TypeScript
- Node.js >= 22
- pnpm workspace
- npm/npx-compatible CLI package
- stdio MCP transport

## Chain and Asset

- Base Sepolia by default
- Base mainnet only as explicit opt-in
- USDC only
- ETH only for gas balance display

## Non-Goals

- Swaps
- Bridges
- DeFi
- USDT
- Solana
- Smart accounts
- Session keys
- Agent marketplace
- Recurring payments
- Auto-approval
- Hosted backend
- Cloud sync
- Analytics
- Telemetry
- Mobile app
- Desktop app
- Browser extension
